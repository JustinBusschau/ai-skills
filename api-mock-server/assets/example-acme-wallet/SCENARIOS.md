## Built-in scenarios (every operation)

| Id | Effect |
| --- | --- |
| `fault.server_error` | 500 with the contract error envelope. |
| `fault.unavailable` | 503 with Retry-After: 30. |
| `fault.rate_limited` | 429 with Retry-After: 30. |
| `fault.timeout` | Holds the connection open past typical client timeouts, then drops it. |
| `fault.connection_reset` | Drops the connection without a response. |
| `fault.malformed_json` | 200 with a truncated JSON body, to test client parsing errors. |
| `delay.<ms>` | Adds latency before responding, e.g. delay.3000 (capped by MOCK_MAX_DELAY_MS). Combines with any other id. |
| `example.<status>` | Returns the spec's own example for that documented status, e.g. example.409. |
